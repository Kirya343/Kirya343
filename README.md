## Project

### Workswap

Full-stack marketplace platform built with Java, Spring Boot, React, Next.js and PostgreSQL.

- Multi-frontend architecture with separate applications for different parts of the platform
- Spring Boot REST APIs
- Separate authentication service
- JWT / OAuth2 authentication and authorization
- WebSocket / STOMP for real-time communication
- RabbitMQ for asynchronous messaging
- JPA / Hibernate with optimized database access and DTO projections
- PostgreSQL and Redis
- S3-compatible object storage for user-uploaded images
- Docker-based deployment
